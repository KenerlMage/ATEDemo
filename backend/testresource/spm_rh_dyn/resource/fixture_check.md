# 读头装夹与外观确认

本环节为**人工操作环节**（清单里 `type: manual`）。设备处于安全状态：供电 3.3 V、转速已停止。

## 请逐项确认

1. 读头已放入装夹夹具，两侧定位销到位，锁紧螺钉已拧紧，读头无晃动。
2. 读头外观无划伤、无变形，光学窗口无油污、无灰尘与异物。
3. 探针与测试点接触良好，线缆无拉扯、无压线。
4. 台面周围无多余工具、无导电异物，防静电手环已佩戴。

## 不符合时怎么办

- 任一项不符合：**先不要继续**，选择「中止测试」，处理完成后再重新执行 TPS。
- 全部符合：选择「继续下一步」，Runner 将执行下一条测试用例（工作电流测试）。
