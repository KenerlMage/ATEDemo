# 示波器探头接入确认

本环节为**人工操作环节**（清单里 `type: manual`），用于在回放信号测试前确认测量通道接线。

## 请逐项确认

1. 示波器 CH1 探头接在读头回放信号输出点（黄色测试柱），探头地线夹可靠夹在测试板 GND 柱上。
2. 探头衰减档位与示波器通道设置一致（1×），通道耦合为 DC。
3. 探针夹无松动、无与其他信号短路的风险。
4. 回放激励线（波形发生器输出）已接入读头激励输入端。

## 不符合时怎么办

- 接线不正确：选择「中止测试」，重新接线后再执行；**不要带着未确认的接线继续后面的幅度 / 频率判定**。
- 接线正确：选择「继续下一步」，Runner 将执行回放信号幅度与频率测试。
