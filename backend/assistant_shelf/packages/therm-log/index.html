温控曲线记录助手

版本 0.9.1 · ATE 装备组 · 发布于 2026-10-08 11:45:00

按固定周期读取温控表温度，绘制多路曲线并记录超温事件；支持导出与测试任务令关联，便于定位热漂移导致的测试异常。

主要功能

  • 温控表连接（Modbus TCP / RTU）
  • 通道与采样周期设定
  • 曲线绘制与超温事件记录
  • 数据导出（CSV）

版本说明

首个可试用版本；支持 8 路采集；告警阈值可按通道设置。

本助手由 ATE Runner 的装备货架下载并启动，当前为演示件：页面内容用于验证 「下载 → 出现在装备助手页 → 启动脚本拉起」的完整链路。正式发布时该目录内为 可执行程序，start.bat 负责以约定参数拉起主程序。
运行环境要求：Windows 10/11 · 温控表支持 Modbus TCP/RTU
