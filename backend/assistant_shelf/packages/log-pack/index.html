测试日志归集助手

版本 1.1.4 · ATE 装备组 · 发布于 2026-10-15 10:05:00

按任务令号扫描执行日志、报告与常数 XML，统一命名后打包，便于问题追溯与产线归档。

主要功能

  • 选择任务令与时间范围
  • 扫描日志 / 报告 / 常数 XML
  • 统一命名并打包
  • 归档清单导出

版本说明

新增常数 XML 一并归集；打包支持分卷；修复中文路径下压缩失败。

本助手由 ATE Runner 的装备货架下载并启动，当前为演示件：页面内容用于验证 「下载 → 出现在装备助手页 → 启动脚本拉起」的完整链路。正式发布时该目录内为 可执行程序，start.bat 负责以约定参数拉起主程序。
运行环境要求：Windows 10/11 · 可读写 reports 目录
