显微镜标记检测助手

版本 1.2.0 · ATE 装备组 · 发布于 2026-10-20 09:30:00

面向显微镜相机的标记检测：枚举相机、设定曝光与增益、单帧取图后做模板匹配，输出标记中心坐标与相对偏差。不进入 TPS 主流程，供现场复核与抽检使用。

主要功能

  • 相机枚举与型号派发（按序列号优先）
  • 曝光 / 增益 / 触发方式设定
  • 单帧取图与标记模板匹配
  • 坐标与偏差输出（CSV 导出）

版本说明

新增多标记批量识别；曝光自动收敛改为按帧统计；修复大分辨率下坐标偏移。

本助手由 ATE Runner 的装备货架下载并启动，当前为演示件：页面内容用于验证 「下载 → 出现在装备助手页 → 启动脚本拉起」的完整链路。正式发布时该目录内为 可执行程序，start.bat 负责以约定参数拉起主程序。
运行环境要求：Windows 10/11 · Basler pylon 8.0 运行时 · 相机 USB3/GigE
