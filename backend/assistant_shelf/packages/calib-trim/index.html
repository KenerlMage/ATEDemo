常数标定计算助手

版本 2.0.0 · ATE 装备组 · 发布于 2026-10-26 16:20:00

读取标定工步的测量结果，按常数模型的字段定义推算标定值，做量程与单调性校验后导出，可直接回填到机器常数模型。

主要功能

  • 选择 PN 与常数模型
  • 导入标定测量结果
  • 推算标定值并做校验
  • 导出为常数导入包片段

版本说明

支持按 PN 批量推算；新增量程越界与单调性校验；导出格式对齐常数导入包。

本助手由 ATE Runner 的装备货架下载并启动，当前为演示件：页面内容用于验证 「下载 → 出现在装备助手页 → 启动脚本拉起」的完整链路。正式发布时该目录内为 可执行程序，start.bat 负责以约定参数拉起主程序。
运行环境要求：Windows 10/11 · 可访问机器常数库
