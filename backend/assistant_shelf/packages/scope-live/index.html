示波器实时观测助手

版本 1.0.3 · ATE 装备组 · 发布于 2026-09-28 14:10:00

绑定已注册测试台的示波器，按设定时基连续采集并绘制波形，支持峰值、频率、上升时间等测量项。断连自动重试，无硬件时可切内置仿真信号源。

主要功能

  • 绑定测试台设备与连接识别
  • 时基 / 通道 / 触发设定
  • 连续采集与波形绘制
  • 测量项与统计导出

版本说明

连续采集增加丢帧统计；测量项支持批量勾选；修复长时运行内存增长。

本助手由 ATE Runner 的装备货架下载并启动，当前为演示件：页面内容用于验证 「下载 → 出现在装备助手页 → 启动脚本拉起」的完整链路。正式发布时该目录内为 可执行程序，start.bat 负责以约定参数拉起主程序。
运行环境要求：Windows 10/11 · 示波器开放 SCPI socket（默认 4000）
