# 装备货架（演示件）

本目录存放装备助手的**货架清单**与**安装包**，供 Runner「装备助手 → 装备货架」页使用。

```
assistant_shelf/
├── catalog.json          货架清单（等价于远端服务返回的 JSON）
├── packages/<id>/        安装包：assistant.json / start.bat / index.html / icon.png
└── installed/<id>/       下载后的本地安装目录（运行时生成，不入库）
    └── _removed/         被移除助手的归档目录（不物理删除）
```

## 与远端的关系

设计上清单由远端服务下发、安装包由远端下载。本次为演示，二者均随程序本地持有：

* `catalog.json` 的 `source` 固定为 `local`，页面上会显示「本地演示清单」；
* 接入远端时只需把 `catalog()` 的数据来源换成接口返回、把 `install()` 的复制源换成下载目录，
  其余（安装目录结构、启动方式、页面表现）不变。

## 安装包清单（assistant.json）

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 与货架条目一致，只允许字母数字与 `. _ -` |
| `name` / `version` / `vendor` | 是 | 页面展示用 |
| `summary` | 否 | 一行摘要 |
| `description` | 否 | 详细说明 |
| `tags` | 否 | 标签，页面上显示前 3 个 |
| `requires` | 否 | 运行环境要求 |
| `entry` | 是 | 启动脚本，相对安装目录，支持 `.bat` / `.cmd` / `.exe` / `.py` |
| `icon` | 否 | 图标文件名，默认 `icon.png` |

## 新增一个助手的步骤

1. 在 `packages/` 下建目录 `<id>/`，放入 `assistant.json`、`icon.png`（建议 256×256）与启动脚本；
2. 在 `catalog.json` 的 `items` 中追加同名条目（名称、版本、摘要、标签、发布说明等）；
3. 重启 Runner，货架页即可下载。安装包体积与文件数由后端统计，无需手写。

## 下载与启动的行为

* **下载**：把安装包整目录复制到 `installed/<id>/`，写入 `install.json`（来源、版本、安装时间、启动次数）；
  已安装时再次下载为覆盖，保留首次安装时间。
* **启动**：读取 `install.json` 的 `entry`，以独立控制台窗口执行；启动记录回写 `install.json`。
* **移除**：目录移动到 `installed/_removed/<id>-<时间戳>/`，不物理删除；若助手进程占用目录，
  会提示先关闭助手窗口。

## 演示件说明

当前 5 个助手的 `start.bat` 以浏览器打开同目录的 `index.html`，用于验证
「下载 → 出现在装备助手页 → 启动脚本拉起」的完整链路。正式发布时该目录内为可执行程序，
`start.bat` 以约定参数拉起主程序即可，不需要改平台侧代码。
