# 05 · 造光刻机的测试装备：ASML 制造链上的四层被测对象

> 本章换一个角度：不看光刻机「怎么工作」，只看它「怎么被造出来」，以及造的过程中**每个部件是怎么被自动测的**。
> 依据见文末「事实与推断的分界」，请务必在汇报时保留这条界线。

## 一、ASML 的制造模式，决定了测试装备长什么样

ASML 不自己造所有零件。它的模式是三层：

| 环节 | 谁做 | 典型对象 |
| --- | --- | --- |
| 模块设计与制造 | 一级供应商（Carl Zeiss SMT 供光学、TRUMPF 供激光、VDL 等供精密加工与机架） | 反射镜、光源模块、精密结构件 |
| 电子与电气集成 | 专业电子制造商（Prodrive、Neways 等） | 驱动板、控制板、线束、传感器接口 |
| 总装与集成测试 | ASML 自己在 Veldhoven 的洁净室 | 整机（光路、工件台、控制系统的联调） |

这套模式产生一个重要后果：**测试被分散在三个地方**——供应商厂内测零件与模块、电子厂测板卡、ASML 测子系统与整机。所谓「ASML 的自动测试装备」，其实是这三处装备的合集，而不是一台机器。

## 二、四层被测对象

### L1 · 材料与光学件（Zeiss SMT）

EUV 反射镜的工序链是公开的：常规抛光 → 计算机控制光学表面成形（CCOS）→ 离子束修形（IBF）→ 镀膜 → 面形与粗糙度量测。每一道工序之后都要量一次，否则修形无从下手。

| 项 | 内容 |
| --- | --- |
| 被测对象 | 微晶玻璃基板、非球面反射镜、镀膜层 |
| 测试项 | 面形误差（nm 级）、表面粗糙度（亚 nm）、镀膜反射率与均匀性 |
| 装备 | 激光干涉仪、白光干涉仪、原子力显微镜、分光光度计 |
| 性质 | **计量级，不是 ATE**：单件、慢节拍、结果要人工判读与工艺反馈 |

把这一层讲成「ATE」是常见错误。它的价值在于**精度可追溯**，在于每件都有完整的面形数据存档。

### L2 · 电子与电气模块（Prodrive / Neways 等）

这是最像传统 ATE 的一层，也是与我们最相关的一层。

| 工序 | 测什么 | 装备 |
| --- | --- | --- |
| SMT 后 | 焊点与贴装质量 | AOI、X 光 |
| 板卡装配后 | 连通性、开路短路、边界扫描 | ICT 在线测试台（针床夹具 + COTS 平台） |
| 上电后 | 功能、时序、功耗、通信 | FCT 功能测试台（定制夹具 + 仪器 + 测试程序） |
| 入库前 | 温循、老化后的参数漂移 | 环境箱 + 数据采集 + 自动判定 |

供应商侧的公开能力可以佐证这层的成熟度：Prodrive 的制造服务页明确列出「全流程测试自动化」与温湿度测试；Neways 公开其半导体业务拥有 6,700 m² 以上、最高 ISO 5 的洁净室，并做微电子封装与高等级组装。**判断**：这一层的测试台多为「COTS 平台 + 定制夹具 + 自写测试程序」，也就是 NI 那条平台化路线的主场。

### L3 · 机电模块与子系统（ASML 模块厂 + 供应商）

工件台、对准传感器、光源模块、片盒 Handlers 属于这一类。它们没有统一的测试标准，测的是机械与控制的动态指标：

| 测试项 | 手段 |
| --- | --- |
| 重复定位精度、行程 | 激光干涉仪 + 光栅尺比对 |
| 振动与模态 | 加速度计 + 激振 + 模态分析 |
| 热漂移与长期稳定性 | 多路温度采集 + 长时数据记录 |
| 通信时延、多轴同步 | 总线分析仪 + 时间戳对齐 |

**判断**：这一层的测试台基本是**非标自研**，因为被测对象本身就是定制的。它们通常以「性能测试台（performance rig）」的形式存在，一台对一类模块，生命周期与产品同长。

### L4 · 整机集成与验收（Veldhoven 洁净室）

ASML 的招聘描述可以直接引用：System Integration & Test Engineer 的职责是「把多个子系统集成为完整系统，负责 qualification、integration 与执行」，岗位要求里出现洁净室经验、统计过程控制（SPC）与 PFMEA。

| 项 | 内容 |
| --- | --- |
| 测什么 | 成像性能、套刻、产率、子系统联调、故障注入 |
| 装备 | 整机自测程序 + 量测机台（YieldStar）+ 数据平台 |
| 性质 | **系统级测试**，与部件级 ATE 不是同一件事 |

## 三、四层对照（与 `ASML制造链与测试装备分层.png` 一致）

| 层 | 被测对象 | 测试重点 | 装备性质 | 执行方 |
| --- | --- | --- | --- | --- |
| L1 | 光学件与材料 | 面形、粗糙度、反射率 | 计量仪器 | Zeiss SMT |
| L2 | 电子与电气模块 | 连通性、功能、时序、温漂 | **平台化 ATE** | Prodrive、Neways 等 |
| L3 | 机电模块与子系统 | 精度、振动、热漂移、同步 | **非标性能测试台** | ASML 模块厂 + 供应商 |
| L4 | 整机 | 成像、套刻、产率、稳定性 | 系统级测试 | ASML 洁净室 |

## 四、事实与推断的分界

| 结论 | 性质 | 依据 |
| --- | --- | --- |
| Zeiss 的镜片工序含抛光、CCOS、离子束修形、镀膜与面形量测 | **公开事实** | ZEISS EUV Optics（euvlitho 2022）、ZEISS SMT 资料 |
| Prodrive 提供全流程测试自动化与温湿度测试 | **公开事实** | Prodrive 制造服务页 |
| Neways 拥有 ISO 5 级洁净室与微电子封装能力 | **公开事实** | Neways 半导体方案页 |
| ASML 设 System Integration & Test 岗位，涉及 qualification、SPC、PFMEA | **公开事实** | ASML 招聘岗位描述 |
| 四层划分与「哪层用什么装备」的对应关系 | **本文判断** | 按半导体设备制造通用工程实践归纳 |
| 具体的测试项清单与节拍 | **本文判断** | 通用实践，不代表 ASML 内部工序卡 |

> 汇报口径建议：讲「这类测试在工程上如何分层、每层需要什么能力」，不要讲「ASML 的某台设备型号是什么」——后者没有公开资料，说了就是编。
