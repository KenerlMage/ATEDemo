# ATE 系统网络拓扑（V2）

16:9 版面（1600×900，等同 33.87×19.05 cm 常规 PPTX 页面）。五层结构自上而下：制造 IT 系统 → ATE 中心系统服务器 → ATE 数据服务器 → 工控机测试站 → 硬件测试台。

## 层次与职责

| 层次 | 组成 | 部署位置 | 主要职责 |
| --- | --- | --- | --- |
| 第一层 | MES、W3、ERP 及其他制造应用 | 制造 IT 系统（制造网侧） | 工单下发、生产追溯、结果回收 |
| 第二层 | Controller 测试装备管理（装备软件管理、测试台管理、装备清单管理、装备需求管理）；Data 测试数据中心（测试数据管理、测试报告管理、机器常数管理、测试看板）；装备工程师与制造生产工程师的装备中心终端 | 黄区大网 | 装备软件与 TPS 下发、报告上传归档、测试台注册与设备管理；测试数据收口、清洗、关联与统计，向装备中心终端提供报表与设备数据 |
| 第三层 | NAS 服务器（装备软件）、NAS 服务器（测试数据） | 数据服务器层 | 装备软件 NAS 提供 TPS 与驱动软件的文件服务；测试数据 NAS 承载测试结果与设备数据的持久化与取用 |
| 第四层 | 工控机测试站（2 个，受同一 Controller 管理）；现场分布式终端 | 黄区小网（经跳板机接入大网） | ATE_Runner 运行环境、预装仪器仪表、工位任务与进度、测试执行与装备管理；TPS 经跳板机接收，测试数据经跳板机上传 |
| 第五层 | 硬件测试台（4 个，每个测试站连接 2 个），布设工装夹具与被测对象 | 现场（随测试站） | 承载被测对象与工装夹具，经 HSSL、串口、网口、GPIB、CAN 卡等接口与测试站双向连接 |

## 连接关系

| 源 | 目标 | 方向与方式 | 承载内容 |
| --- | --- | --- | --- |
| 制造 IT 系统 | ATE 中心系统服务器（Controller） | 单向（虚线，左列） | 工单 / 工序下发 |
| ATE 中心系统服务器（Data） | 制造 IT 系统 | 单向（虚线，右列） | 测试结果回传 |
| ATE 数据服务器（测试数据） | ATE 中心系统服务器（Data 测试数据中心） | 单向（虚线） | 测试数据取用 |
| NAS 服务器（装备软件） | ATE 中心系统服务器 | 双向（虚线） | TPS 与驱动软件读写、文件存取 |
| NAS 服务器（装备软件） | 跳板机 → 工控机测试站 | 单向（实线，两段：NAS → 跳板机 → 测试站） | TPS 与装备软件下发、管理指令；跳板机按安全策略管控 |
| 工控机测试站 | 跳板机 → NAS 服务器（测试数据） | 单向（虚线，两段：测试站 → 跳板机 → 测试数据 NAS） | 测试结果与设备数据上传 |
| ATE 中心系统 | 装备工程师 / 制造生产工程师 · 装备中心终端 | 单向（实线，自层带边缘引出） | 设备管理与用例编排；测试报表查询与设备数据查看 |
| 工控机测试站 | IE / 操作员 · 现场分布式终端 | 单向（实线，自层带边缘引出） | IE：工位任务与实时进度；操作员：测试执行、装备管理、装备助手 |
| 工控机测试站 | 硬件测试台 | 双向（实线，每站 2 台） | 连接方式：HSSL、串口、网口、GPIB、CAN 卡等 |

> 说明：第一层为制造 IT 系统；第三层 NAS 按用途划分为装备软件与测试数据，不再采用主备关系；跨网连线一律改为直线并自跳板机上下边界接入、引出 —— 装备软件 NAS 经跳板机向工控机测试站下发 TPS；工控机测试站的测试数据经跳板机存入测试数据 NAS；第一层与第二层之间拆为两条单向连线（左侧工单 / 工序下发、右侧测试结果回传）；左侧网络区与右侧终端区之间增设竖向隔离线。第五层不再单设「接入方式」文本框，连接方式直接标注在第四、五层之间的双向箭头上。

> 配图说明：第一层不配图；第二至第五层每张卡片内部左侧各嵌入一张配图，标题位于配图右侧；第三层 NAS 卡片正文改为灰色小文本框，仅列数据类型；右侧四个终端共用一个配图，配图位于文字下方并通栏填充卡片下半部。配图取自装备实拍与开放许可图库（Wikimedia Commons），仅作示意。

## 版面与结构变更

| 变更项 | 上一版 | 本版 |
| --- | --- | --- |
| 画布 | 1800×1670（A3 竖版） | 1600×900（16:9，常规 PPTX 页面） |
| 第二 / 三层 | 数据服务器在上、中心系统在下 | 已对调：中心系统在上、数据服务器在下 |
| 数据处理中心 | 320×240，位于中心系统带右侧 | 更名 Data，与 Controller 等宽等高并排 |
| 第一层名称 | 企业 IT 系统（办公网侧） | 制造 IT 系统（制造网侧） |
| 第三层 NAS | 主 / 备份关系（备份同步） | 装备软件 / 测试数据（按用途划分） |
| 跨网连线 | 部分连线跨越跳板机色带 | 一律在跳板机处断开接入，不再跨越色带 |
| 测试数据路径 | 测试站 → 数据服务器 | 测试站 → 跳板机 → Data |
| 第五层 | 含「接入方式」文本框 | 删除该框；连接方式标注在第四、五层双向箭头上 |
| 文字对齐 | 仅标题居中、正文左对齐 | 所有文本框内文字全部居中 |
| 层间箭头 | 头部 7px、线宽 1.7 | 头部 5px、线宽 1.5，端点微侵入文本框 |
| 第五层连接方式 | VISA / 串口 / 网口 | HSSL / 串口 / 网口 / GPIB / CAN 卡等 |
| 配图位置 | 层带左侧单张照片 | 第二至五层每张卡片内部左侧各一张；第一层不配图 |
| NAS 卡片正文 | 两行说明文字 | 灰色小文本框，仅列数据类型 |
| 终端配图 | 卡片左侧小图 | 文字下方通栏图；四个终端共用一张 |
