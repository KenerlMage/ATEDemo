ATE 自动测试装备 · Demo 项目说明

前后端分离的自动测试工具：Vue3 前端 + FastAPI 后端 + pytest 执行引擎，含登录、用例列表、用例执行与进度反馈的完整闭环。

Vue 3前端框架 (Vite + vue-router)
FastAPI后端 API 服务 (Python)
pytest测试用例执行引擎
6 条Demo 用例 (含参数化)
6 个HTTP 接口

系统架构

Vue3 前端
登录页 / 执行页→ HTTP /api FastAPI 后端
登录日志 · 用例收集 · 任务调度→ 子进程 pytest
执行 test_cases/ 用例

前端开发服务器通过 Vite 代理 /api 到后端 8000 端口；后端以后台线程 + 子进程方式运行 pytest，逐行解析输出并维护任务状态，前端轮询获取进度。

核心执行流程

1. 登录输入用户名 → POST /api/login → 写入 logs/login.log → 前端跳转执行页
2. 拉取用例GET /api/testcases → 后端 pytest --collect-only 收集用例 → 前端展示列表
3. 选择并执行点击用例 → POST /api/execute → 后端立即返回 task_id
4. 后台运行后台线程启动 pytest -v 子进程，逐行解析 PASSED/FAILED/SKIPPED 计算进度
5. 进度反馈前端 600ms 轮询 GET /api/tasks/{id} → 更新状态徽标 / 进度条 / 实时日志
6. 结果落盘进程退出码决定 completed / failed，写入 logs/execution.log，前端展示总结与历史

接口清单

方法路径说明
POST/api/login登录，校验用户名并写登录日志
GET/api/testcases获取可执行用例列表
POST/api/execute启动用例执行，返回 task_id
GET/api/tasks/{id}查询进度 / 状态 / 日志输出
GET/api/tasks最近执行记录
GET/api/health健康检查

快速启动

方式一（推荐）：双击 D:\ATE\start_all.bat，自动安装依赖并启动前后端。

方式二：手动

# 终端 1 - 后端
cd D:\ATE\backend
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000

# 终端 2 - 前端
cd D:\ATE\frontend
npm install
npm run dev

浏览器打开 http://127.0.0.1:5173，输入任意用户名登录，选择用例点击「执行用例」。

新增用例

在 backend/test_cases/ 下新建 test_xxx.py 写 pytest 用例即可，前端「刷新」后自动出现。想演示失败状态，把 demo 中断言预期改错即可。
