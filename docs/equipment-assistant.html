1. 两个页面的定位

装备属性配置 /equipment

回答"这台测试台上装了哪些设备、各自的连接参数是什么、能不能改"。

  • 设备清单不是独立维护的,直接来自各测试台注册时该类型 BOM 清单
  • 按测试台分组切换,支持关键词搜索与「仅看可编程 / 未配置」筛选
  • 可编程设备右键 → 修改设备属性 / 恢复 BOM 默认值 / 复制资源地址 / 变更历史
  • 非可编程设备(夹具、探针组等)属性只读,右键给出明确提示

装备助手 /assistant

回答"怎么用这些设备干活"。

  • 工具以卡片呈现:名称、协议、能力清单、可用性
  • 单击 / 双击卡片选中 → 点右上角「运行工具」启动
  • 首期:数字示波器(泰克 MSO54 方案,SCPI over socket)
  • 其余工位(万用表 / 可编程电源 / 电子负载)已预留卡片

  • 格式:IP/主机名、端口范围 1-65535、串口号 COM3 样式、波特率 300-1000000、资源地址字符集、通道号字符集

4. 装备助手:数字示波器工作流

1 选中工具点击卡片(单击选中、双击直接运行);未选中或工具未上线时「运行工具」给出明确提示。
2 绑定设备下拉列出已注册测试台中的网口设备,示波器优先;显示 IP:端口 与所属测试台。设备来自注册 BOM,不另维护清单。
③ 连接与识别选择「仿真信号源 / 真实仪器」后点「进入仿真」或「连接并识别」；仿真模式可不选设备（自动使用内置仿真信号源 SIM-SCOPE）：建立 SCPI socket 会话（仿真为内存会话），执行 *IDN?，并回读时基与各通道状态。
4 操作运行 / 停止 / 单次、自动设置(AUTOSet EXECute)、时基 ×2 ÷2 与常用档位、通道 ON/OFF 与量程 / 耦合(DC·AC·GND)。
5 读取与呈现取波形(DATa:* + CURVe? + WFMOutpre:* 标定)后用 Canvas 绘制在 10×8 工业风网格上,按通道量程标注刻度。
6 测量峰峰值、幅值、频率、周期、平均值、有效值、上升/下降时间;每项带来源标签(实测 / 模拟 / 无效)。
7 追溯面板底部实时显示 SCPI 命令日志(发送 / 应答 / 提示),便于现场排查与复现。

5. 仿真信号源（无硬件也能看正弦波）

示波器面板左侧新增仿真信号源区块：点「一键仿真」即可进入仿真（不选设备也行，后端自动使用内置仿真信号源），面板随即出现模拟正弦波与测量值。

控件范围 / 选项说明
波形类型正弦波 · 方波 · 三角波 · 锯齿波 · 直流 · 噪声切换后波形与测量值立即重算；测量项按样本自算，与波形一致
频率10 Hz – 1 MHz（16 档对数滑块）改频率时自动重算时基，保持「屏内周期」不变
幅度 Vpp0.1 – 10 V同步自动挑 1-2-5 档 V/div，波形约占总高 60%；手动改过档位后不再自动适配
偏置-5 – +5 V均值测量随偏置变化（可用于验证 MEAN）
噪声0 – 0.5（× 幅度）叠加均匀噪声，波形不再是理想曲线
屏内周期1 · 2 · 5 · 10直接决定时基：时基 = 周期数 /（10 × 频率），右侧实时显示 µs/div

自洽性校验（后端算法）

  • 时基与频率配套：屏内恰好 N 个周期，避免高频时整屏不到一个周期变成直线；
  • 频率测量用带迟滞的过中点检测（先越过下限再越过上限才计一个上升沿），噪声不会在中点附近造出伪穿越，实测频率与设定频率一致（1~10 周期、10 Hz~1 MHz 均对得上）；
  • 幅度按示波器习惯取 Top/Base 直方图均值差，与偏置无关；
  • 仿真数据统一标注 source=simulate、测量标签显示「模拟」，不冒充实测；切到「真实仪器」后仿真参数不影响实测波形。

方法路径说明

POST/api/tools/oscilloscope/connect建立会话:mode=real|simulate、allow_fallback
POST/api/tools/oscilloscope/actionidentify / run / stop / single / autoset / timebase / channel / acquire / measure / frame / close
GET/api/tools/oscilloscope/state会话状态:连接态、IDN、时基、通道、命令日志
