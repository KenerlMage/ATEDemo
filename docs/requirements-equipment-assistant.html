需求文档 · 装备属性配置 与 装备助手

日期：2026-09-13　模块：前端 /equipment（装备属性配置）、/assistant（装备助手）+ 后端 testbench_registry / instrument_tools / testbench_lifecycle

一句话背景：测试台注册完成后，现场需要能就地查看并修改设备连接参数、对测试台做装备级运维，并能在没有硬件的情况下用同一套界面把仪器"跑起来"验证流程。

一、核心需求（先说重点）

# 核心需求 关键约束
C1 设备清单只有一个来源：装备属性配置页的设备来自各测试台注册时该类型 BOM 清单 不二次维护、不另存一份
C2 只允许改连接参数：可编程设备可改 IP/端口/串口/资源地址并写回注册库 型号·厂商·类别·用途属 BOM 元信息，只读
C3 一个页面承载三类现场动作：测试台导出（待注册 + 已注册）、装备自检、报告中心 同路由内三栏切换，不新增两个侧栏菜单项
C4 装备助手 = 工具卡片 + 会话式仪器控制，首期打通数字示波器（泰克 MSO54，SCPI over socket） 工具以卡片注册，后续仪器按同一形态扩展
C5 仿真是一等公民：无硬件也能完成演示与自检，且与实测严格区分 仿真数据标 simulate、测量标「模拟」，不冒充实测

二、装备属性配置（/equipment）

编号 需求 说明 / 验收点
R1 由原「测试装备」页改造为「装备属性配置」 回答"这台测试台装了哪些设备、连接参数是什么、能不能改"
R2 设备清单按测试台分组，支持关键词搜索与「仅看可编程 / 未配置」筛选 数据源：GET /api/testbench/devices（各测试台 BOM 设备拍平，含资源串）
R3 可编程设备右键 → 修改设备属性 网口：IP/主机名·端口·协议·备注；串口：口号·波特率；USB/GPIB：资源地址·通道号
R4 属性弹窗按接口类型渲染，元信息只读 型号/厂商/类别/用途不在提交范围内
R5 保存前双重校验 + 变更留痕 格式校验（端口 1–65535、COM3 样式、波特率 300–1000000 等）+ 同测试台内 IP:端口 不允许被两台设备占用（前后端同一套规则）；字段级前后值保留最近 10 条，可查「变更历史」
R6 右键附带「恢复 BOM 默认值」「复制资源地址」 默认值来自预设 BOM
R7 非可编程设备（夹具、探针组等）只读 右键给出明确提示，不参与校验
R8 测试台导出：待注册（草稿）与已注册都可导出 勾选多台 → 「导出选中」，或「导出全部已注册」；导出内容自描述作用范围（pending/registered/selected/all）与状态构成（已注册 x 台 / 草稿 y 台）
R9 导出记录统一进报告区 类型标签统一「测试台导出」，历史记录读取时重映射，无需迁移数据
R10 三栏切换：装备属性配置 / 测试台装备自检 / 装备报告中心 同一路由内 v-show 切换，栏位与地址栏 hash 深链同步
R11 装备级运维：初始化 / 终止 / 自检 自检结果（含每项清单）在界面直接显示报告；非程控设备只做信息项、不参与结论判定
R12 报告区 「打开本地资源管理器」定位报告目录 + 历史硬件自检报告 / 导出清单，按类型过滤
R13 默认测试台可见可用 新环境下装备页应直接看到「SPM 读头动态测试台」及其 BOM 设备
R14 TPS 运行环境面板（同页承载） 显示 workspace 路径、公共 conftest 版本、SQLite 投影统计与驱动规格表，提供初始化 / 同步按钮；「TPS 运行目录」列出运行副本与结果徽标并可清理

三、装备助手（/assistant）

编号 需求 说明 / 验收点
A1 以卡片形式提供控制设备的小工具 卡片含名称、协议、能力清单、可用性；单击/双击选中 → 「运行工具」启动
A2 工具注册可扩展 首期：数字示波器（泰克 MSO54 方案）；万用表 / 可编程电源 / 电子负载预留卡片
A3 设备绑定来自注册库 下拉列出已注册测试台中的网口设备（示波器优先），显示 IP:端口 与所属测试台；不另维护清单
A4 示波器基本操作 连接并识别（*IDN? + 回读时基与通道状态）、运行/停止/单次、自动设置、时基 ×2 ÷2 与常用档位、通道 ON/OFF 与量程 / 耦合（DC·AC·GND）
A5 波形读取与呈现 取波形后 Canvas 绘制 10×8 工业风网格，按通道量程标注刻度
A6 测量项带来源标签 峰峰值、幅值、频率、周期、平均值、有效值、上升/下降时间，每项标注 实测 / 模拟 / 无效
A7 命令日志 面板底部实时显示 SCPI 发送 / 应答 / 提示，便于现场排查与复现
A8 仿真模式：无硬件也能看波形 「一键仿真」不选设备也能进（后端用内置仿真信号源）；仿真与真实仪器并存、切换明确
A9 可调仿真信号源 波形 6 种（正弦/方波/三角/锯齿/直流/噪声）；频率 10 Hz–1 MHz（16 档）；幅度 Vpp 0.1–10 V（自动 1-2-5 档 V/div，手动改过后不再自动）；偏置 ±5 V；噪声 0–0.5；屏内周期 1/2/5/10（换算时基并显示 µs/div）
A10 仿真算法自洽 时基与频率配套（屏内恰好 N 个周期）；频率测量用带迟滞的过中点检测（噪声不造假穿越）；幅度取 Top/Base 直方图均值差、与偏置无关；切回真实仪器后仿真参数不影响实测

四、非功能与设计约束

  • 单一事实源：注册库（JSON）为唯一事实源，SQLite 只做投影；装备页读注册库，不新建存储。
  • 改哪里：默认 IP/端口 → testresource/testbench_presets.json；校验规则 → testbench_registry.py；工具卡片 / 示波器 → instrument_tools.py；导出与报告 → testbench_lifecycle.py。
  • 导航：装备助手为左侧导航项，「测试台导航」固定在最下方；窄屏（≤900px）转顶部横向导航。
  • 界面风格：延续紫色 + 白底工业风，配色只改 style.css 的 :root 变量。
  • 验证方式：以构建 + 接口端到端断言为准（无 GUI 自动化节点时不做浏览器渲染巡检）。

五、验收标准（简表）

项 验收点
数据源一致 注册一台 8 设备测试台 → 装备页接口返回 8 台设备
属性写回 改 IP/端口后注册库更新，冲突被前后端同时拦截，变更历史可查
导出范围 scope 为 pending/registered/selected/all 且 by_status 计数正确，弹窗显示状态构成
三栏深链 三个栏位切换后地址栏 hash 正确，刷新后停在原栏位
装备自检 结论与清单在界面可见，报告可在资源管理器中定位
仿真 6 种波形均可显示；设定频率/幅度/偏置与测量值一致；source=simulate、测量标「模拟」
回归 示波器仿真 52 条断言、装备运维 47 条、导出 40 条、默认测试台 28 条全绿

六、本期范围外（明确不做）

  • 不为装备数据单独建一套存储（避免双份事实源）。
  • 不允许修改型号 / 厂商 / 类别等 BOM 元信息。
  • 不为「装备自检」「报告中心」各新增一个侧栏菜单页（统一为同路由三栏）。
  • 仿真数据不得进入实测报告或作为实测结论。
