# ATE 系统网络拓扑

五层结构：企业 IT 系统 → ATE 数据服务器 → ATE 中心系统（Controller）→ 工控机测试站 → 硬件测试台。
Controller 部署在黄区大网且全局唯一；工控机测试站位于黄区小网，经跳板机（安全策略管控）接入；各类终端统一接入在右侧。

## 层次与职责

| 层次 | 组成 | 部署位置 | 主要职责 |
| --- | --- | --- | --- |
| 第一层 | MES、W3、ERP 及其他企业应用 | 企业 IT 系统（办公网侧） | 工单下发、生产追溯、结果回收 |
| 第二层 | NAS 服务器（多台，主备关系，用于数据备份）、MCP 服务器（单实例） | 数据服务器层 | 为 Controller 提供文件服务与数据备份、MCP 能力 |
| 第三层 | Controller 后端服务器（全局唯一）；装备工程师与制造生产工程师的装备中心终端 | 黄区大网 | 装备软件与 TPS 下发、报告上传归档、测试台注册与设备管理、测试报表与设备数据查看 |
| 第四层 | 工控机测试站（2 个，受同一 Controller 管理）；现场分布式终端 | 黄区小网（经跳板机接入大网） | ATE_Runner 运行环境、预装仪器仪表、工位任务与进度、测试执行与装备管理 |
| 第五层 | 硬件测试台（4 个，每个测试站连接 2 个），布设工装夹具与被测对象 | 现场（随测试站） | 承载被测对象与工装夹具，经 VISA / 串口 / 网口接入测试站 |

## 连接关系

| 源 | 目标 | 方向与方式 | 承载内容 |
| --- | --- | --- | --- |
| 企业 IT 系统 | Controller 后端 | 双向（虚线） | 工单、制造数据与测试结果交互 |
| NAS 主 / 备份 | Controller 后端 | 双向（虚线） | TPS 与驱动软件读写、文件存取；主备之间按策略同步备份 |
| MCP 服务器 | Controller 后端 | 双向（虚线） | MCP 服务调用（单实例） |
| 装备工程师 / 制造生产工程师终端 | Controller 后端 | 单向（实线） | 设备管理与用例编排；测试报表查询与设备数据查看 |
| Controller 后端 | 工控机测试站 | 单向（实线，经跳板机） | 装备软件与 TPS 下发、管理指令；跳板机按安全策略管控 |
| 工控机测试站 | 现场分布式终端 | 单向（实线） | IE：工位任务与实时进度；操作员：测试执行、装备管理、装备助手 |
| 工控机测试站 | 硬件测试台 | 一对多（实线，每站 2 台） | VISA / 串口 / 网口，每台测试台均具备这三种接入方式 |

> 说明：MCP 服务器按单实例表达；NAS 采用多台并建立主备备份关系，用于数据备份；
> 硬件测试台的接入方式统一为 VISA / 串口 / 网口，每台测试台均具备这三种接入方式。
