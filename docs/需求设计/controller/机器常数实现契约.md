# 机器常数实现契约（给并行开发者）

> 目的：多个模块并行实现时，只靠本文件对齐接口、表结构、返回格式与测试方式。
> 需求编号见 `docs/需求设计/机器常数功能模块.md`。

## 一、硬约束

1. **只改自己的文件**。共享文件（`app.py`、`ate_db.py`、`api_v1.py`、`main.py`、前端 `App.vue`）已由主控改好或另行分配，不要动。
2. 每个 Controller 模块自带 `register_routes(app, base_dir, db_path=None)`；`app.py` 已按 try/except 挂载，模块建好即生效。
3. 返回 JSON 统一为 `{"success": bool, "message": str | None, ...}`；出错时 `success=false` 且 `message` 为中文可读原因，不抛裸异常给前端。
4. 时间统一 `datetime.now(timezone.utc).astimezone().isoformat(timespec="seconds")`。
5. 所有写操作写审计字段（`operator`、`created_at`）。
6. 不引第三方新依赖（Controller 只用标准库 + fastapi/pydantic；Runner 已有 paramiko 可选用）。

## 三、模型文件规范（`Module.xml` / `<SN>_Module.xml`）

```xml
<MachineConstants schema="ate.constants.v2" module="SPM_RH" pn="SPM-RH-01"
                  version="2026.11.01" calibrated="false" sn="" generatedAt="...">
  <Meta product="1000-A" subsystem="SPM" name="SPM 读头机常数" />
  <Fields>
    <Field key="gain_offset" label="增益偏移" type="float" unit="mV"
           default="0.0" min="-50.0" max="50.0" value="" />
    <Field key="head_grade" label="读头等级" type="enum" unit=""
           default="B" values="A,B,C" value="" />
  </Fields>
  <Calibration sn="..." operator="..." tpsId="..." taskId="..." at="..." />
</MachineConstants>
```

规则：
- `module` + `pn` 唯一标识模型；字段 `key` 在模型内唯一。
- `calibrated="false"` 为结构模板；`calibrated="true"` 且 `sn` 非空为标定实例，此时每 `Field` 必须带 `value`。
- `type ∈ {float,int,str,bool,enum}`；`float/int` 必须有 `min`/`max` 且 `min ≤ default ≤ max`；`enum` 必须有 `values`。
- 哈希：文件字节的 sha256 十六进制小写；包清单 `manifest.json` 含 `{"version": "...", "files": [{"path": "...", "sha256": "...", "size": 123}]}`。

## 四、模块职责与文件边界

### Controller

| 文件 | 负责 AR | 提供路由 |
| --- | --- | --- |
| `const_import.py` | SR01-AR01、SR01-AR02 | `/api/v1/constants/import/full`、`/import/partial`、`/backups`、`/backups/{id}/restore` |
| `const_approval.py` | SR01-AR03、SR01-AR04 | `/api/v1/constants/requests*`、`/approval-roles`、`/groups/apply`、`/groups/applies` |
| `const_catalog.py` | SR01-AR05、SR01-AR06、SR01-AR07、SR01-AR08、SR02-AR09 | `/api/v1/constants/models/{pn}/{key}/history`、`/api/v1/settings/tps-badge`、`/api/v1/metadata/menu`、`/api/v1/constants/field-mapping*` |

### Runner

| 文件 | 负责 AR | 说明 |
| --- | --- | --- |
| `const_runtime.py` | SR02-AR01、SR02-AR02、SR02-AR03 | 解析 `machine_constants`、写入/清除、范围校验；纯函数 + `register_routes(app, db_path=None)` |
| `manual_check.py` | SR02-AR04、SR02-AR05 | manual check 门禁、标定标识；依赖 `const_runtime` |
| `calib.py` | SR02-AR06、SR02-AR07、SR02-AR08 | 本机标定、paramiko 下位机标定（sqlite/pgsql）、下位机连接配置 |

## 五、公共函数签名（跨模块调用必须一致）

Controller（`const_import.py` 导出）：

```python
def import_full(blob: bytes, filename: str, operator: str = "", db_path=None) -> dict
def import_partial(blob: bytes, filename: str, operator: str = "", db_path=None) -> dict
def list_backups(pn: str = "", model_key: str = "", limit: int = 100, db_path=None) -> dict
def restore_backup(backup_id: int, operator: str = "", db_path=None) -> dict
```

Controller（`const_approval.py` 导出）：

```python
def create_request(kind: str, pn: str, model_key: str, payload: dict, applicant: str, db_path=None) -> dict
def decide_request(request_id: int, approve: bool, approver: str, reason: str = "", db_path=None) -> dict
def list_requests(status: str = "", db_path=None) -> dict
def push_result(request_id: int, channel: str = "dry-run", db_path=None) -> dict
```

Runner（`const_runtime.py` 导出）：

```python
def parse_bindings(tps: dict) -> list[dict]          # 归一化 machine_constants 段
def resolve_models(bindings: list[dict], catalog: dict) -> dict   # 绑定 -> 可写入集合
def validate_values(models: dict, strict: bool = True) -> dict     # 逐字段范围校验
def write_constants(target: Path, models: dict, header: dict) -> dict
def clear_constants(target: Path, keys: list[str] | None = None) -> dict
```

Runner（`manual_check.py` 导出）：

```python
def needs_check(step: dict) -> bool
def submit_decision(task_id: str, step_index: int, decision: str, note: str = "", operator: str = "") -> dict
def pending_checks(task: dict) -> list[dict]
```

Runner（`calib.py` 导出）：

```python
def build_local(sn: str, pn: str, model_key: str, values: dict, header: dict, out_dir: Path) -> dict
def fetch_remote(target: dict, query: str, mapping: list[dict], out_dir: Path) -> dict
def register_routes(app, base_dir: Path, db_path=None) -> None
```

## 六、测试方式

Controller：

```powershell
cd D:\ATE\MockController
& 'D:\ATE\MockRunner\backend\.venv\Scripts\python.exe' -m pytest tests\test_const_<你的模块>.py -q --basetemp=.pytest_tmp
```

- 每个测试用 `tmp_path` 独立 db 与临时 repo，不碰 `repo/` 与 `controller.db`。
- 必须覆盖：正常路径、拒绝路径、幂等/重复调用、审计落库。

Runner：

```powershell
cd D:\ATE\MockRunner\backend
& '.\.venv\Scripts\python.exe' -m pytest tests\test_const_<你的模块>.py -q --basetemp=.pytest_tmp
```

## 七、验收口径（写测试时照这个写）

| AR | 必测点 |
| --- | --- |
| SR01-AR01 | 正常包通过且模型数正确；篡改一个字节整包拒绝；重复导入同版本幂等 |
| SR01-AR02 | 非标准包（无 manifest/签名）拒绝；覆盖后旧结构进 `const_backup`；restore 后结构还原 |
| SR01-AR03 | 新建待审批期间 Runner 不可见；通过后可见；驳回带理由；推送写 `const_push_log`（dry-run） |
| SR01-AR04 | 无权限用户审批被拒且原因明确；授组后通过；用户组申请状态流转 |
| SR01-AR05 | 列表按产品/子系统过滤正确；历史按时间倒序含差异摘要 |
| SR01-AR06 | 同模型可重复添加、别名重复被拒、来源枚举校验 |
| SR01-AR07 | 徽标位置三态（before/after/icon）落库并可读回 |
| SR01-AR08 | 二级菜单含三项且条目数与库一致 |
| SR02-AR01 | 有/无 `machine_constants` 段都能解析；解析失败给字段级错误 |
| SR02-AR02 | 写入生成 `<SN>_<Module>.xml`；清除恢复默认值；按字段选择生效 |
| SR02-AR03 | 越界拒绝并列出全部违规字段；strict=false 时警告放行 |
| SR02-AR04 | 未确认不回传；确认回传一次；驳回带理由且不回传 |
| SR02-AR05 | 步骤/面板/报告三处标识一致 |
| SR02-AR06 | 本机 Demo 生成 `<SN>_Module.xml` 且值被替换、范围合规 |
| SR02-AR07 | sqlite 与 pgsql 两种方言各一条；连接失败/超时/缺数据三类错误明确 |
| SR02-AR08 | 凭据不明文回显；连通性测试返回时延 |
| SR02-AR09 | 映射缺失报未映射字段；scale/offset 换算可逆 |
