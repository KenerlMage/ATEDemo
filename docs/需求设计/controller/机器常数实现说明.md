## 二、关键实现决策

0. **信任根在 MCS**：包必须带 `source.system`（白名单校验）、`batch_id`、`content_digest`；Controller 自己的导出标记 `ate-controller-export-v1` 在导入通道一律拒绝。
0. **模板与实例分流**：`<Module>.xml` 进 `constant_model`，`<SN>_<Module>.xml` 进 `const_calibration`；文件名与 XML 的 `calibrated`/`sn` 矛盾即整包拒绝，实例永不覆盖模板。
0. **全量导入默认保留 SN 实例**：换版本不该把已标定的 SN 数据清掉；需要清空时显式传 `purge_calibrations=true`。
1. **凭据不明文**：下位机密码与密钥路径经机器绑定混淆后落 `remote_targets.json`，接口只回 `password_set` / `key_path_set`，不回原值。
2. **推送 dry-run**：本轮按你的要求不真实外发。`push_result` 写 `const_push_log`（`status=dry-run`），非 dry-run 通道记 `skipped` 并说明未配置真实通道；MES 回传同样是 dry-run，日志落 `logs/mes_push.log`。
3. **manual_check 与 manual 分离**：`manual` 是操作员判定步骤结果（pass/fail/abort/cancel）；`manual_check` 是执行后的人工确认门禁，确认才回传。两者可同时存在，互不替代。
4. **标定标识三处一致**：Controller 清单徽标、Runner 步骤徽标、Runner 标定模式条共用「标定」文案与紫色（`--accent`）。
5. **步骤快照透传**：`manifest.steps_of` 增加 `manual_check` 与 `calibration`，并把 `type` 归一为 `calib`，否则执行页与门禁模块都读不到。
6. **sqlite / pgsql 双方言**：`calib.py` 按 `db` 分支——sqlite 走 `sqlite3 <db> "<sql>"`，pgsql 走 `psql -A -t -c "<sql>"`，口令经 `PGPASSWORD` 环境变量传递。
7. **全量导入也写备份**：否则「可回滚到前一版本」没有实现基础；旧结构进 `const_backup`，`reason=全量导入覆盖前备份`。

## 五、未覆盖范围（明确说明）

1. **真实 MES 联调**：回传是 dry-run，写本地 `logs/mes_push.log`，未接生产接口。
2. **审批推送通道**：未接企业微信/邮件；`push_result` 只落库并标记 `dry-run`/`skipped`。
3. **真实 SSH 下位机**：paramiko 已安装且失败路径用真实 socket 验证，但没有可登录的 Linux 目标机，成功取数路径仅在单测中打桩验证；sshd 的 `AcceptEnv PGPASSWORD` 未验证。
4. **Oracle / MySQL 方言**：只实现 sqlite 与 pgsql（按你给的两种）。
5. **跨进程并发**：写入用临时文件 + `os.replace` 原子替换，未加跨进程文件锁；多工位同时写同一 `<SN>_Module.xml` 未压测。
6. **自动打开标定界面**：标定 TPS 执行不会自动跳到标定面板，需人工打开常数视图。
7. **历史版本回滚的 UI**：`restore` 接口与前端按钮已就绪，但只回滚单个模型结构，没有「整版本回滚」入口。
8. **计量溯源与证书**：不在本轮。
9. **MCS 真实签名算法未对接**：支持 `hmac-sha256`（共享密钥经 `ATE_CONSTANT_SIGNING_KEY`），未拿到 MCS 实际算法与密钥；未配密钥时签名只标注 `unverified` 不阻断（按需求可接受）。
10. **MCS 导出工具未联调**：契约按清单字段设计，未用 MCS 真实导出包跑过；若其字段名不同，只需在 `const_package._meta` 加别名映射。
11. **SR02-AR02 审计字段不全**：写入/清除会把 `operator` / `tpsId` / `taskId` 写入 XML 的 `Calibration` 节点，但没有写 Runner 审计表，也没有记录「前后值」。需求里"记录前后值"这一项仍未实现。
10. ~~SR02-AR09 换算不可逆~~：已补 `reverse=true`（`source = (target - offset) / scale`），并加往返测试（12.5 → 24.0 → 12.5）。scale=0 时明确拒绝。
11. ~~Controller→Runner 关联桥未验证~~：已补 `parse_bindings` 对 `machine_constant_bindings`（新版）与 `constant_bindings`（旧版 `{version,pn,models[]}`）的支持；`set_tps_constants` 同时写两个字段，避免各说各话。已用真实 HTTP 验证：Controller 保存 2 条（读头1/读头2）→ 取回清单 → Runner 解析出同样 2 条别名。
12. **SR01-AR07 仅接口级验证**：徽标三态（before/after/icon）只验证了接口存取与前端读取，未逐态截图核对视觉位置。
13. **结果报告无标定分区**：`/tasks/{id}/calib` 提供分区数据、页面有徽标与标定条，但生成的 HTML 报告未把标定结果单独分区。
