# 工业相机装备助手（Basler pylon 8.0.0）

ATE Runner 的装备助手之一，位于「装备助手」页的工具卡片中，卡片标识 `camera-basler`。
进入工作区后可直接对相机做参数设置、曝光控制与数据保存，无需写脚本。

## 一、能力范围

| 分组 | 能力 | 说明 |
| --- | --- | --- |
| 会话 | 连接 / 识别 / 断开 | 支持真实相机与仿真两种模式；仿真模式生成确定性灰度帧，无需硬件 |
| 参数设置 | 采集几何 | 宽 / 高 / 水平偏移 / 垂直偏移（16–20000 px） |
| 参数设置 | 像质与曝光 | 像素格式、曝光时间、自动曝光档位、增益、自动增益 |
| 参数设置 | 采集节奏与触发 | 目标帧率、触发模式、触发源、取帧超时 |
| 参数设置 | 仿真场景 | 图样（均匀场 / 水平渐变 / 棋盘格 / 阶跃边缘 / 中心光斑 / 纯噪声）、基准亮度、噪声幅度 |
| 曝光控制 | 绝对值设定 | 10 µs – 60 s，越界自动夹取 |
| 曝光控制 | 倍数微调 | ÷2 / ×2，便于快速找合适亮度 |
| 曝光控制 | 预设档位 | 100 µs / 500 µs / 1 ms / 5 ms / 10 ms / 20 ms / 50 ms / 100 ms |
| 曝光控制 | 自动曝光 | 按目标平均灰度迭代，收敛带 ±6%；亮度不随曝光变化时停止拉高并保留原曝光 |
| 数据保存 | 单帧抓取 | 抓取即落盘为 PNG，返回尺寸、字节数、sha256 与亮度统计 |
| 数据保存 | 连拍序列 | 指定帧数与间隔，逐帧落盘并给出实际帧率、帧间亮度极差 |
| 数据保存 | 导出归档 | 按业务命名（如 `PN1234-AOI`）复制到 `exports/`，供报告引用 |
| 数据保存 | 预览与下载 | 帧列表按时间倒序，可预览、单帧下载 |

## 二、界面入口

1. 左侧导航「装备助手」→ 卡片区第 2 张「工业相机」；
2. 单击选中后点右上角「运行工具」（或双击卡片）；
3. 工作区三栏：左「参数设置」、中「帧预览 + 采集动作」、右「曝光控制 + 最近帧」。

## 三、接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/tools` | 工具卡片清单（含本助手，`available: true`） |
| GET | `/api/tools/camera/info` | 能力清单：参数分组、曝光预设、图样、像素格式、落盘根目录 |
| GET | `/api/tools/camera/sessions` | 当前会话列表 |
| POST | `/api/tools/camera/connect` | `{mode: simulate\|real, serial}` → 返回会话键 |
| POST | `/api/tools/camera/disconnect` | `{key}` |
| GET | `/api/tools/camera/state?key=` | 会话状态：idn、参数、设备信息、帧数、最近帧、pylon 版本 |
| POST | `/api/tools/camera/params` | `{key, params}` 批量设置；`{key, reset: true}` 恢复默认 |
| POST | `/api/tools/camera/exposure` | `{key, exposure_us}` 或 `{key, scale}` 或 `{key, auto}` |
| POST | `/api/tools/camera/auto-exposure` | `{key, target_mean, max_rounds}` → 每轮曝光与均值 |
| POST | `/api/tools/camera/grab` | `{key, note}` → 抓一帧并落盘 |
| POST | `/api/tools/camera/sequence` | `{key, count, interval_ms, prefix}` |
| GET | `/api/tools/camera/frames?limit=` | 最近帧列表 |
| GET | `/api/tools/camera/frame?path=&download=` | 读取 PNG（路径越界返回 400） |
| POST | `/api/tools/camera/save` | `{key, path, name, subdir}` 导出归档 |

## 四、数据落盘

```
backend/logs/camera_frames/
├── 20261101/                     # 按采集日期分层
│   ├── cam_112523_0001.png
│   └── seq/                      # 连拍序列（按前缀分目录）
│       ├── seq_0000.png
│       └── seq_0001.png
└── exports/                      # 导出归档（按业务命名）
    └── PN1234-AOI.png
```

* `backend/logs/` 已在 `.gitignore` 中，采集产物不会进入版本库；
* 帧路径只允许落在该根目录内，`..` 与绝对路径一律拒绝（接口返回 400）。

## 五、实现要点

* 驱动复用 `backend/drivers/camera.py`（`driver_key = basler-pylon`），
  助手模块只做会话管理、落盘命名与接口封装，不重复实现 pylon 调用；
* 参数表单由后端 `PARAM_GROUPS` 描述，前端按类型渲染，新增参数只需改一处；
* 参数批量设置先合并校验、后提交，非法入参不会污染会话状态；
* 自动曝光区分「不响应」与「未收敛」两种结果，前者保留原曝光，避免无意义拉高；
* 真实模式未装 pypylon 时连接直接失败并给出安装指引，仿真模式不受影响。

## 六、与 TPS 的关系

本助手面向调试与产线辅助观察，不进 TPS 主流程、不改变测试基线；
TPS 内的相机采集仍由 `ate_drivers` 的相机接口在用例中完成。
