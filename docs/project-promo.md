# ATE Runner — 自动测试设备（ATE）测试管理平台

> 面向产线/工控机场景的一体化自动测试解决方案：**用例管理 → 一键执行 → 实时反馈 → 报告留存 → 智能分析**，开箱即用。

---

## 一、一句话介绍

**ATE Runner** 是一套前后端分离的自动测试设备（ATE）测试管理工具，把"测试程序集（TPS）管理、测试执行、进度反馈、报告生成、历史追溯"串成一条完整链路。操作员只需在界面选择 TPS、输入 UUT 名称，即可自动完成从环境初始化、测试用例执行到环境终止的全流程，并获得一份可追溯的 HTML 测试报告。

## 二、核心亮点

| 亮点 | 说明 |
| --- | --- |
| 🚀 一键执行 | 选择 TPS → 输入 12 位 UUT → 自动按「环境初始化 → 测试用例 → 环境终止」顺序执行，失败即中止并标记后续步骤跳过 |
| 📊 实时进度 | 前端 600ms 轮询，逐步展示 待执行 / 执行中 / 通过 / 失败 / 跳过 状态、进度条与实时输出 |
| 🌳 装备树导航 | 左侧按 **项目 → 测试对象（DUT）→ TPS** 三级树组织测试资源，与产线装备结构天然对齐 |
| 🧾 报告自动生成 | 每次运行自动生成含装备信息（项目/DUT/UUT）的 HTML 报告，右下角内嵌查看，无需额外软件 |
| 🔍 记录可追溯 | 运行记录存入 SQLite，支持按 12 位 UUT 名称查询历史测试记录，点击即看对应报告 |
| 📡 远端 TPS 源 | TPS 可存放在远端服务器统一管理，在线自动拉取；离线自动回退本地默认 TPS，产线断网不中断 |
| 📂 TPS 快速导入 | 通过文件选择器一键导入 TPS 定义文件，校验后立即加入装备树，零代码扩展测试流程 |
| 🔒 License 授权 | Ed25519 非对称签名离线授权，防篡改/防伪造，支持设备绑定与有效期，适合交付给客户的商业场景 |
| 🤖 AI 失败分析 | 内置 AI 分析入口：配置 API 地址与 Key 后，一键把测试日志+报告交给 AI，自动给出失败原因排序与排查建议 |
| 🖥 多方式部署 | 本地一键启动（bat）/ Docker 容器化 / PyInstaller 免安装打包，适配 Linux 服务器与 Windows 工控机 |

## 三、典型使用流程

```
登录（License 校验）
   ↓
选择 TPS（装备树 / UUT 反查 / 导入新 TPS）
   ↓
输入 UUT 名称（12 位英数）→ 点击执行
   ↓
实时观察步骤状态与进度
   ↓
查看 HTML 测试报告
   ↓
（失败时）AI 分析失败原因 / 按 UUT 查询历史记录
```

## 四、适用场景

- **产线功能测试**：PCBA / 整机 / 模块的下线检测，一键执行标准化测试流程
- **测试程序集管理**：多个项目、多种被测对象（DUT）的 TPS 统一组织与版本管理
- **质量追溯**：每台被测设备（UUT）的测试记录留存，出现质量问题时快速回溯
- **售后/返修判定**：输入 UUT 名称即可查询该设备历史测试情况
- **测试团队提效**：非开发人员也能执行复杂测试流程，报告自动生成，减少人工记录

## 五、功能清单

- ✅ License 授权与注册页导入（登录前置校验）
- ✅ 装备树（项目 → DUT → TPS 三级，折叠/选中）
- ✅ TPS 顺序执行（init → 用例 → teardown，失败中止 + 跳过）
- ✅ 逐步状态实时反馈 + 进度条 + 实时日志
- ✅ HTML 测试报告（含项目/DUT/UUT 装备信息卡）
- ✅ SQLite 运行记录库 + UUT 查询
- ✅ 按 UUT 反查对应 TPS 并自动加载
- ✅ 远端 TPS 源（在线/离线自动切换，离线保持默认 TPS）
- ✅ TPS 文件导入（校验 + 立即生效）
- ✅ 测试日志自动生成（逐步 PASS/FAIL/耗时/输出）
- ✅ AI 测试失败分析（可配置 API 地址与 Key）
- ✅ 数据源状态徽章（● 在线 / ● 离线）

## 六、技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | Vue 3 + Vite + vue-router + 原生 CSS（工业风深色主题） |
| 后端 | FastAPI (Python 3.10+，开发环境 3.13) + pytest 执行引擎 |
| 存储 | SQLite（运行记录，零配置）/ 文件系统（报告、日志、TPS 定义） |
| 授权 | Ed25519 非对称签名（cryptography） |
| 部署 | 一键 bat / Docker Compose（Nginx + uvicorn）/ PyInstaller 方案 |

## 七、快速体验

```bat
:: 一键启动（自动装依赖 + 启动前后端）
D:\ATE\start_all.bat

:: 浏览器访问
http://127.0.0.1:5173

:: 预置授权文件（导入即可用）
D:/ATE_ENV/ate_runner.lic
```

> 演示用例：`backend/test_cases/test_demo.py` 6 条（上电电压 / 断电电流 / UART 握手×3 / 固件校验）+ `demo_tps.json` 8 步完整流程（初始化 → 6 用例 → 终止）。

## 八、商业价值

1. **交付即用**：预置 Demo TPS 与用例，开箱演示；客户侧只需替换 `test_cases/` 与 `testresource/` 即可落地真实测试流程。
2. **授权可控**：按客户/设备/有效期签发 License，保护软件价值，支持商业收费模式。
3. **部署灵活**：Linux 服务器或 Windows 工控机均可运行，离线环境也能用（本地回退 + 离线授权）。
4. **可追溯可分析**：测试记录、日志、报告三位一体，配合 AI 分析，降低产线排障人力成本。
