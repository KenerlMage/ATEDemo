01

口径与范围

这份清单是示波器家族的对外函数契约：TPS 与上层工具只按这里的名字和参数调用，不直接拼 SCPI。厂商差异（泰克、R&S 等）收在驱动的 COMMANDS 表里，函数签名不变。

项约定
调用入口do(action, **params)，返回统一结果结构
能力名scope.*，与 ACTIONS 的键一致
单位时间一律 SI 秒（s、s/div），电压 V、V/div，不出现 ms/us 混写
波形口径由采样点自算测量项，不依赖各家 :MEASure，保证跨品牌可比
仿真同一函数在 simulate 模式下确定性输出，可复现

04

数据结构

四个不可变数据类，单位写在结构里，不靠调用方记忆。

结构字段单位
TimebaseSetupscale_s_per_div, divisions, offset_s, window_ss/div ／ s
ChannelSetupname, enabled, scale_v_per_div, coupling, offset_v, probe_ratioV/div ／ V
Waveformchannel, samples, x_start_s, x_incr_s, unit, sourceV ／ s
Measurementkind, value, unit, quality随类型
波形契约samples 是纯数字数组，时间轴由 x_start_s + i × x_incr_s 推出，不重复存时间列。
05

测量项与枚举

八个测量项是全平台统一口径。未列出的项不要临时加：加之前要确认仿真与真机都能算出同一个值。

项含义单位
PK2PK峰峰值V
AMPLITUDE幅度（高电平减低电平）V
FREQUENCY频率Hz
PERIOD周期s
MEAN平均值V
RMS有效值V
RISE上升时间s
FALL下降时间s

枚举

耦合 DC / AC / GND；仿真波形 sine / square / triangle / sawtooth / dc / noise。

垂直档位

13 档：1mV 到 10V/div，只接受表内值，避免设成仪器不认的中间值。

06

错误与返回值

所有动作走同一个结果结构；失败抛异常并带稳定错误码，上层按码分支，不匹配中文文案。

字段说明
ok是否成功；失败时抛异常，所以正常返回恒为 true
action / requested归一化后的动作名与原始请求
value主结果；测量返回列表，波形返回对象
unit测量类必带
detail附加信息（非标准键会被收进这里）
qualitysimulated / good，报告据此标注数据来源
elapsed_ms / driver_version耗时与驱动版本，进结果文件
错误触发处置
DriverError参数非法（如测量项不在枚举内）改调用，不要重试
ProtocolError应答无法解析核对该固件命令格式
DriverTimeout读超时查链路与触发设置
UnsupportedCapability调了未声明的能力先 supports() 再调
07

调用示例

下面这段是能力层演示脚本里真实跑过的一段，输出值取自本次运行。

drv = TekMsoScope(cfg, mode="simulate", alias="SCOPE-01")
drv.do("scope.timebase", scale_s_per_div=0.001)
drv.do("scope.channel", name="CH1", scale_v_per_div=1.0)
wf = drv.do("scope.acquire_waveform", points=200)["value"]
m  = drv.do("scope.measure", items=["PK2PK", "FREQUENCY"])["value"]

# 实测（仿真）: points=200, x_incr_s=5.025e-05
#              PK2PK=2.4375 V, FREQUENCY=999.5 Hz
写法建议先 supports("scope.measure") 再调；跨品牌 TPS 只写能力名与参数，不写 :MEASUrement 这类厂商命令。
