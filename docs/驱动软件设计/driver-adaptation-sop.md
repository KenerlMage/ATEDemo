# 驱动适配手册（SOP）

版本 v1.0 · 可执行规程

## 1 适用范围与角色

适用三场景：新型号纳入既有家族、新协议接入既有家族、新增设备族。流程终点为"进入下一次发版"，非现场安装。

| 角色 | 职责 | 产出 |
|---|---|---|
| 驱动开发 | 实现驱动包、仿真应答、自测 | 厂商包目录 |
| 平台维护 | 契约兼容、能力键与家族边界 | 契约变更记录 |
| 发布工程 | 执行门禁、出包、写版本号 | 安装包与发布记录 |
| 测试 | 真机联调、用例回归 | 联调记录与结果文件 |

## 2 前置条件

1. 设备编程手册可覆盖全部待实现动作。
2. 具备可建链目标（实物或仿真器），`*IDN?` 应答稳定。
3. 家族归属已确认；新增平台级能力键需平台维护复核。
4. SDK 已在 `PYTHONPATH`，`import ate_drivers` 成功。
5. 驱动键、型号清单、接口与后端命名确定。

## 3 流程总览

SOP-01 族判定 → SOP-02 建包 → SOP-03 实现 → SOP-04 自测 → SOP-05 契约门禁 → SOP-06 真机联调 → SOP-07 注册接入 → SOP-08 打包门禁 → SOP-09 发版记录。

SOP-05、SOP-08 为强制门，未过不得进入后续步骤。

## 4 步骤明细

| 编号 | 输入 | 操作 | 输出 | 判定 / 异常 |
|---|---|---|---|---|
| SOP-01 | 设备文档、能力表 | 对照 `capabilities.py` 选能力；无对应能力用 `vendor.<厂商>.*` | 能力清单 | 家族必选能力缺失退回；不得新造平台级键 |
| SOP-02 | 能力清单 | 建 `driver.json` / `driver.py` / `__init__.py`，声明 `INTERFACES`、`BACKENDS`、`MODELS` | 可导入空壳包 | 清单与类属性不一致不通过 |
| SOP-03 | 命令集 | 写 `COMMANDS`；动作方法先 `ensure_open()`；测量返回带单位；仿真模式不写链路 | 驱动实现 | 脏应答与量纲错误为高频缺陷 |
| SOP-04 | 驱动包 | `python -m ate_drivers.kit.cli check vendors\<pkg>` | 检查报告 | 逐项修复后复跑 |
| SOP-05 | 检查报告 | 核对 19 项全过并归档 | 门禁记录 | 任一失败阻断发版 |
| SOP-06 | 真机 | 逐动作执行，记录量纲、超时、错误码 | 联调记录 | 与仿真差异写入注释与手册 |
| SOP-07 | 注册数据 | 注册页选择设备类型，确认落库字段 | 注册记录 | 类型缺失报错属预期 |
| SOP-08 | `payload/app` | `python packaging\check_drivers.py --backend <payload>\app` | 打包门禁结果 | 存在未解析类型即阻断出包 |
| SOP-09 | 门禁与联调记录 | 写版本号、变更单、文档索引 | 发布记录 | 无记录不发版 |

## 5 门禁判定（19 项）

| 组 | 编号 | 检查内容 | 判定 |
|---|---|---|---|
| 元数据 | C01 / C17 / C18 / C19 | 类元数据、型号派发、连接方式、传输后端 | 清单与类属性一致，型号与端点可解析 |
| 契约 | C02 / C03 / C04 / C05 | 契约兼容、能力声明、能力已实现、命令表 | 能力键即 `ACTIONS` 键，方法可调用 |
| 行为 | C06 / C07 / C08 / C09 | 全能力可仿真、结果结构、测量单位、类型化错误 | 零参可执行，测量必带单位 |
| 健壮性 | C10 / C11 / C12 / C13 / C14 | 会话生命周期、拆除安全、确定性、实例隔离、别名 | 重复开关幂等，两次仿真一致 |
| 依赖 | C15 / C16 | 无第三方硬依赖、弃用项有说明 | 仅标准库与平台包 |

门禁对象为 SDK，验证契约正确性；打包门禁对象为 `payload/app`，验证装进包里可运行。二者不可互相替代。

## 6 发布检查表

1. 能力键与动作键一致（C04 输出）
2. 全部能力零参可执行（C06 输出）
3. 测量值带单位（C08 输出）
4. 仿真输出可复现（连续两次一致）
5. 关闭安全且幂等（C10 / C11 输出）
6. 注册库全部类型可解析（打包门禁统计行）
7. 真机逐动作通过（联调记录）
8. 版本号与变更单已写（`installed_version.json` 与变更单）

## 7 异常与回滚

| 现象 | 判定 | 处置 |
|---|---|---|
| 提示设备类型缺失或非法 | 注册数据未带类型 | 补选类型，禁止驱动内加兜底 |
| 动作报不支持 | 能力未声明或未实现 | 补 `ACTIONS` 与方法，重跑门禁 |
| 仿真读回与预期不符 | 写命令污染应答队列 | 仿真模式不下发写链路命令 |
| 升级后数据缺失 | 保留项被覆盖或指纹误判 | 整包回滚，核对保留清单解析路径 |
| 升级中断 | 切换未完成 | 按待切换清单恢复旧版本目录 |

回滚粒度：整包唯一形态，不存在"驱动退回、平台未退回"的中间状态。

## 8 记录与变更

| 记录 | 内容 | 保存位置 |
|---|---|---|
| 门禁记录 | 19 项结果、时间、执行人 | 变更单附件 |
| 联调记录 | 设备序列号、固件版本、逐动作结论 | 测试归档 |
| 变更单 | 新增能力、影响类型、版本号 | 版本库 |
| 文档更新 | 功能点、视图、函数清单同步 | `docs/驱动软件设计` |

变更分类：新型号纳入属常规变更，仅需门禁与联调；新增能力键或修改动作语义属契约变更，需平台维护复核并同步更新函数清单与 TPS 说明。
